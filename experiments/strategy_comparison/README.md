# 2026-11-19 Agent 策略对比实验

这是一次独立实验编排，复用现有 Agent、模型、Runner 和评分器。它不扩展产品配置或改变 `start.cmd` 的默认行为。

协议在 `protocol.json`：ReAct、Plan and Execute、Reflection 从相同源码、数据和训练种子 2026 开始。统一训练一个共享基线；每种模式最多五个候选、60 次模型请求尝试、10 次补丁，单次实验上限 600 秒。规划、反思和请求重试均计入各自的 60 次调用。最多 16 次训练尝试，预留实验时间最多 9,600 秒；不自动核验服务商或 AutoDL 账单。

各模式的源码、实验历史、预算和轨迹隔离。每轮只允许一个候选尝试，只在主指标提高且满足原基线守护指标时保留已验证源码，否则恢复本模式当前最佳版本。历史包含真实源码差异和独立评分。每次训练从头开始，不继承 checkpoint 权重。

本次执行曾因控制端暂停而在基线训练成功后错过预测阶段。独立脚本的适配器会验证相同作业身份并复用已完成的基线，不额外重训；远端训练/预测进程组仍分别受 480/120 秒监督限额。控制端暂停不消耗该远端配额，墙钟等待、控制器 CPU 时间和服务器作业耗时分别记录；策略效率比较使用服务器训练/预测时间与模型调用/Token，而非桌面等待时间。

仅查看协议：

```powershell
.\.venv\Scripts\python.exe -B -m experiments.strategy_comparison.run
```

实际执行本实验：

```powershell
.\.venv\Scripts\python.exe -B -m experiments.strategy_comparison.run --run
```

API 设置仍从本地 `.reclab/agent.env` 读取。结果写入短路径 `.reclab/sc/sessions/`，避免 Windows 临时快照路径过长，包含整体报告、各模式报告、每轮轨迹、源代码快照、预测和评分。结束时自动生成可在浏览器阅读的 `report.html` 和便于复制的 `report.md`，终端显示中文结论与报告路径；原始 `report.json` 继续保存，可用 `--json` 输出供脚本处理。失败、中断或候选不足也会生成报告，并明确说明缺失证据。未产生等量有效候选时报告为 `incomplete`，不宣布策略胜者。单个种子、每模式一次搜索只支持本轮观察，不能据此宣称某种策略普遍更优；最终测试集不参与搜索。

2026-11-20 的执行结果见 [中文报告](../../reports/strategy-comparison-20261120/report.md)、[HTML 报告](../../reports/strategy-comparison-20261120/report.html)和[原始实验记录](../../reports/strategy-comparison-20261120.json)。15 个轮次全部结束，实际训练 13 次（包含一次共享基线），5 个候选获得有效评分。ReAct 为 5 次训练、1 个有效分数；Plan and Execute 为 3 次训练、1 个有效分数；Reflection 为 4 次训练、3 个有效分数。未训练的轮次来自规划格式失败或补丁预算耗尽后的重复候选拦截。

本轮守住 Recall 边界的最高 NDCG@20 是 ReAct 的 0.081267，基线为 0.080042，相对提升 1.53%。报告保留失败、真实源码差异、独立评分哈希、调用与作业耗时，并指出 Reflection 新增分支未进入实际训练路径等实现问题。验证集同时用于 checkpoint 选择和候选搜索，独立评分器没有消除这种选择偏差；本轮不足以给三种方法作一般性排名。
