# 第5周：主研究者、独立审计与持久化

目标是理解研究责任、证据审计和宿主控制的边界。当前实现见 [独立审计说明](../../research-audit.md)。

## 学习与编码

1. 走读协作策略中的两个 `RunSession`，找出各自输入、工具和恢复状态。
2. 解释为什么审计先看证据，再看研究结论；指出冻结证据仍可能不完整。
3. 检查审计工具箱只返回快照，不能读取任意路径或调用训练工具。
4. 离线注入越权工具、非法审计、超时和工具执行中断，确认不放行候选、不重置预算。
5. 对照同预算单 Agent，统计错误放行、误报、证据不足和实际耗时；不预设审计有效。

## 验收边界

- 独立会话不共享聊天历史；任务和宿主证据通过明确接口交接。
- 请求预算共享，训练额度仍由既有工具控制；审计无权申请额外训练。
- 审计未通过，候选不能接受；审计通过仍需满足验证集与诊断规则。
- 逻辑权限隔离不等于独立容器；真实服务验收与离线测试分开报告。
