# 每周学习正文的写作标准

每周文档必须有可以直接学习的正文，不以任务清单、知识点名称或外链代替讲解。内容先在本目录审阅，再合入对应周文档和飞书；不另建一套飞书学习文档。

每个主题包含：读者遇到的问题、原理与关键术语、具体例子、与RecLab代码/实验的对应、练习、参考答案及少量有说明的官方资料。能运行的例子要实际验证；伪代码和未来设计明确标注，不能声称未实现功能已验收。

用户有数学、推荐算法与PyTorch基础。已有指标简要复习，重点解释Agent规划、工具、隔离执行、RAG、状态、评测与工程的新知识。不要替用户勾选“已掌握”；手算、运行、解释和自测后再确认。

源码：week-01.md至week-08.md。第一周配套可运行示例：docs/examples/week01_scoring.py。
