在限定预算或时间下自主完成模型优化的Agent. 用户提供模型的建模目标、训练/验证数据集、评测指标和预算/时间限制，Agent自主提出优化点，进行实验。


Agent工作流程：
理解背景 -> 提出假设 -> 模型实验 -> 结果分析和得出结论

理解背景包括：理解训练目标和总结历史实验
提出假设包括：根据历史实验提出优化假设；根据调研文献提出优化假设；根据提出的假设给出可验证的中间过程指标；给出可验证的收益链路和该优化下的潜在风险
实验包括：修改代码（模型代码、过程指标代码）；模型训练/验证评估；实验结果记录（实验配置、实验checkpoint）
结果分析和得出结论包括：根据最终指标和过程指标确定实验结论（保留/否定）；撰写实验报告


对每一个模型训练优化的任务，Agent需要构建：知识库wiki、代码库git、数据（训练和验证）

知识库wiki: 采用markdown格式，存储调研的文献总结和本模型历史实验报告
代码库git: 存储历史实验的模型代码、过程指标评估代码等
数据：训练数据和验证数据集或入口



Agent设计要求：
1. 代码简洁，框架清晰
2. 将功能都设计为工具，减少耦合，可拓展性强
3. 考虑长期记忆和短期记忆

实施顺序、基线复用规则、四阶段工具化重构及记忆功能方案见[重构与功能完善实施方案](implementation-plan.md)。先完成重构及验收，再实施实验账本、记忆、文献调研和过程指标。
