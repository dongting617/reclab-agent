# 新版研究工作台与指标图

更新：2026-11-24。状态：正式页面已接入真实会话、报告和事件流，相关回归及浏览器验收通过；本轮发布已同步主分支的完整独立审计和可观测实现。审计能力的专项证据见[独立审计说明](research-audit.md)，不使用界面截图证明模型效果。

## 打开工作台

在仓库根目录、已安装依赖的 Python 环境中运行：

```bash
pip install -e ".[service]"
python -m reclab_agent.cli.web --root . --port 8000
```

浏览器访问 `http://127.0.0.1:8000`。CLI 与 Web 读取同一个 RunStore，以及 `reclab.json` 配置所指向的本地研究会话目录。新 Git 工作树不会自动包含原目录中被忽略的数据、实验产物或会话；未找到本地评分证据时，界面会显示未核验，不会补造曲线。

默认没有训练执行器：可以查看会话、登记等待配置的任务、取消等待任务、运行本地证据演示；打开页面不会启动训练。运行中的研究会话不提供伪造的停止按钮。

静态设计原型继续保留在 `/static/prototype.html`，或直接用浏览器打开 [prototype.html](../reclab_agent/web/static/prototype.html)。原型使用明确标记的示例数据，与正式页面分离。

## 如何阅读页面

- 左栏搜索并筛选会话，区分研究与本地证据演示；`/` 聚焦搜索，窄屏通过顶部按钮展开列表。
- 概览分别显示运行状态、指标结论、实际阶段记录、独立审计与需要关注的事项。缺少阶段记录不会显示为全部完成。
- 核心目标图使用任务的主指标：虚线为基线，点为已核验且可比较的评分，阶梯线为截至当时的最佳合格结果。关键改进突出每次刷新最佳的候选、实际值、相对基线变化和相对上次最佳的差值。
- 更高的原始分数若未满足护栏、必需过程要求或已启用的审计门禁，仍保留为空心点，不进入最佳曲线。未核验、不可比较的评分只保留在实验表和状态记录中；无分数失败不填零分。
- 多策略报告通过实验组选项分别绘制，不能把不同组的文件顺序当作一条研究时间线。基线为零时，相对变化显示无法计算。
- 点击图点、关键改进、状态条目或实验名称，查看实际源码差异、评分路径及身份、过程诊断和审计原始记录。文件路径可复制，不提供任意本机文件读取入口。
- 假设与改动、实验对比、研究报告和运行事件各有独立页面。原始 JSON 默认折叠；日志支持角色、类型和关键词筛选，默认最近 200 条，可加载更早记录。

所有判断以宿主报告视图为准。比较要求已核验评分、明确一致的数据集、协议、种子和环境；已记录的评估上下文也必须一致。缺少必要比较身份不会获得提升标记。声明了必需过程指标时，必须有通过的记录；启用审计时，必须有对应候选的审计通过记录。单种子验证集结果不称为统计显著。

## 请求与恢复行为

会话切换关闭旧事件流并取消旧请求，同时按会话代次丢弃迟到响应；事件按序号去重，由 SSE 重连续读。事件触发刷新做合并，三秒轮询作为补充，列表与详情分别避免重叠请求。

报告和会话详情若在刷新中不是同一个快照，延后重读，不混用新指标与旧摘要。网络失败保留最后成功内容及更新时间。用户离开日志底部后不强制滚动，已展开的事件保持打开。

登记任务失败后，相同内容沿用原幂等键重试；修改内容后使用新键。等待任务可以取消，运行会话仍需执行端确认停止。页面显示的请求、评分、预算用量均来自已记录字段，未报告的费用不视为免费。

## 验收

```bash
node --check reclab_agent/web/static/app.js
node --check reclab_agent/web/static/workbench-charts.js
node --test tests/frontend/*.test.cjs
python -m unittest tests.test_report_progress tests.test_user_report tests.test_workbench -q
```

- 17 项前端逻辑测试通过：包括原型 10 项、真实控制器 7 项，覆盖候选标记、详情、筛选、键盘标签页、A→B→A 迟到响应、SSE 去重、幂等重试、请求合并、失败保留内容及日志位置。
- 安装 service/test 可选依赖的现有 WSL 环境中，33 项报告及 HTTP 回归通过。覆盖连续刷新最佳、下降、持平、未评分、零基线、缺失比较身份、未核验评分、护栏、过程要求、审计门禁和不改写原报告。
- 浏览器通过真实 API 验收四类结果、图点与改进详情、实际差异、实验表、事件流，以及隔离任务的登记和取消；1440/1280/390 断点检查通过。窄屏页面没有整体横向溢出，图和表格局部滚动。验收页未记录 JavaScript 错误。
- 浏览器测试使用临时目录内明确标记的示例证据；还检查了正式工作树的本地参考演示。没有启动远程 GPU、调用付费模型或改写历史成绩。

前端独立开发阶段曾有 3 项旧多智能体迁移测试失败。发布前已整合主分支的替代实现和新测试，当前状态以[本轮验收记录](../reports/workbench-acceptance-20261124.md)的整合回归结果为准；旧阶段结果仍按历史记录保留。

发布整合后的完整回归为 **551 项：543 通过、8 跳过，无失败或错误**；前端 17 项逻辑检查通过。审计失败的展示与主分支既有报告语义兼容。
