# 2026-11-24 版本修改说明

本次提交汇总当前工作区中尚未提交的研究审计、工具命名、评测和可观测改动。

## Agent 协作

- 移除旧 Planner / Executor / Reviewer 协作实现及专属文件，改为主研究者与独立审计者。
- 研究者与审计者使用独立上下文和工具权限，审计者先查看冻结证据，再接收研究结论。
- 共享请求预算，失败请求也计入；检查点绑定任务、模型、权限、Prompt 和证据身份，未确定的工具副作用要求核验。
- 集中维护角色 Prompt，增加内容哈希、结构化输出校验和有界协议纠正；审计通过不替代独立验证集评分。

## 工具与代码可读性

- `RecLabToolbox` 改为 `EvidenceToolbox`，`RemoteTools` 改为 `RemoteToolbox`。
- `toolbox.py`、`context.py`、`group.py`、`citations.py` 分别改为 `optimization_toolbox.py`、`study_context.py`、`tool_group.py`、`citation_validation.py`，同步更新引用。
- `run_tools()` 改为 `run_loop()`，补充 RunSession 方法注释；单工具包装函数改名，区分注册与按名称分派。
- 新增 tools 逐文件职责说明，区分业务工具、工具箱、共享状态和支持代码。模型可调用工具名称保持原协议。

## 持久化与可观测

- 新 Trace 增加研究会话、父运行、任务、阶段、角色、候选、实验、UTC 时间和递增序号；协调器、研究者与审计者共享写入器。
- 模型请求记录开始、结果或错误，包含请求 ID、耗时、错误类别、模型名称与系统指令／输入／工具定义的 SHA-256。
- 工作台事件视图兼容已有 SQLite 任务和旧 Trace；不补造历史时间、不改写历史评测成绩。
- 增加子进程强制退出后的预算恢复、不重放工具、待核验副作用、事件游标续读和不完整尾行保护检查。

## 评测与文档

- 增加独立审计评测及派生汇总脚本，保存原始失败、版本身份和源码快照核验记录。
- 最新固定快照开发集：单 Agent 28/30、64 次请求；独立审计模式 27/30、124 次请求。未通过案例为 API 连接错误或超时，不宣称审计优于单 Agent。
- 补齐 27 个此前没有实际请求的案例，复用原单 Agent 和已尝试案例，不通过重跑失败筛选成绩。
- 更新 README、架构、代码导航、四天面试准备、审计及可观测说明。

## 验证与限制

- 本次可观测增量相关 61 项测试通过：58 项离线核心／恢复／事件检查，3 项本地 HTTP/SSE 检查；9 个修改文件语法检查通过。
- HTTP 测试在沙箱内受 Windows socketpair 初始化阻塞，停止后在沙箱外通过。可观测验收没有调用外部模型 API 或 GPU。
- 其他既有验收记录在对应报告中保留；上述 61 项不是当前整个仓库完整回归结果。
- 同一 Trace 仍要求单控制器写入；未承诺任意中断点、断电或远端 GPU 故障自动恢复。
